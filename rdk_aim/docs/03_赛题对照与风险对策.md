# 赛题对照与风险对策

## 一、指标逐条对照

| 题目要求 | 指标 | 本方案怎么保证 | 代码位置 |
|---|---|---|---|
| 基本(1) 循迹 N=1~5 圈，t<=20s | 圈数/时间 | RCT6 负责，地瓜派只收发状态 | `link.py` |
| 基本(2) 任意位置姿态，2s 内命中，D1<=2cm | 时间 + 精度 | 螺旋扫描捕获 + 像素闭环 | `acquire.*` / `aim.py` |
| 基本(3) 指定位置，任意瞄准方向，4s 内命中 | 时间 | 全周扫描（`acquire.mode=full`） | `state_machine.py` |
| 发挥(1)(2) 行驶中连续发光，N=1/2 圈，D1<=2cm | 运动跟踪 | 超前补偿 + 拐角加强 + 滑行 | `aim.py` |
| 发挥(3) 沿 r=6cm 红圈画圆，D2<=2cm，同步<1/4圈 | 轨迹 + 同步 | 靶面坐标生成圆 + 单应映射 + 拐角重同步 | `trajectory.py` |

### 精度余量估算

以 1280x720、fx=700px 为例（约 ±45° 视场）：

| 距离 | 1 像素对应靶面位移 | 允许 2cm 对应 |
|---|---|---|
| 0.5m | 0.71mm | 28 px |
| 1.0m | 1.43mm | 14 px |
| 1.58m（对角最远） | 2.26mm | 8.8 px |

视觉闭环的稳态误差主要受**光斑质心噪声**与**死区**限制：典型亚像素质心噪声
<0.3px，死区设 3px，最远处仍有约 3 倍余量。
**结论：精度指标没有风险，风险全在时间与机械。**

## 二、风险清单（按严重程度排序）

### R1 【严重】H723 上电启动 3.4s 与「2s 内命中」直接冲突

**事实**：`yuntai_task.c` 的启动链

```
BMI088 初始化 (~0.2s)
  -> CALIBRATE_DELAY      (2.0s)   纯延时等驱动器自检
  -> CLOSED_LOOP_DELAY    (0.5s)   进闭环
  -> SET_MODE_DELAY       (0.5s)   速度模式
  -> LOCK_ATTITUDE_DELAY  (0.2s)   锁基准
  = 约 3.4s
```

这期间电机未使能、云台是"软"的（能被手掰动）。

**冲突**：基本要求(2) 要求"启动瞄准模块 2s 内击中靶心"。

**对策（按推荐顺序）**：

1. **把计时起点与上电分离**。赛题原文并未规定"合上开关的瞬间开始计时"，
   只要求两个电源由独立开关控制、并用发光管显示供电状态。
   实操上：先合上瞄准模块开关（自检完成、云台变硬、指示灯亮），
   再由 `main.py run` 触发 2s 计时窗口。
   本程序支持 `app.timer_start: trigger`。
2. **压缩固件启动时间**（更稳妥）：
   - `CALIBRATE_DELAY` 2.0s -> 0.6s（需实测驱动器自检时间；
     当年设 2.0s 是因为"发太早会被忽略"，但不是必须 2.0s）
   - `CLOSED_LOOP_DELAY` / `SET_MODE_DELAY` 各 0.5s -> 各 0.2s
   - 目标：**上电到能接收偏置 < 1.0s**，给视觉留 1s
3. 若以上都做不到，在报告里把"计时口径"写清楚，并演示
   "上电指示 -> 云台就绪 -> 开始"这个流程。

### R2 【严重】云台绕线：跑一圈相对车身必然绕 360°

**推理**：稳定环要保持**绝对方位**不变，则偏航电机相对车身的转角

```
phi_rel(t) = (靶标绝对方位) - (车身航向 t)
```

小车跑一圈航向转 360°（逆时针），靶标绝对方位基本不变，
因此 **phi_rel 每圈净变化 -360°，跑两圈 -720°**。

**后果**：没有滑环的话，导线会在 1~2 圈内被拧死，甚至把云台拽歪。

**对策**：

1. **首选：滑环（导电滑环）**，或内部走线预留 3 圈以上的服务环。
2. **次选：自动解绕流程**。本程序支持：每次测试前先发 `MODE = UNWIND`，
   云台把相对偏航角以安全速度转回 0（此时激光关闭），然后重测零位、
   重新捕获靶标。现场流程：

   ```bash
   python main.py unwind     # 解绕
   python main.py run        # 正式跑
   ```

3. **注意**：不能靠"让云台跟着车转"来避免绕线——那样激光就离开靶面了。
   这是物理必然，躲不掉，只能靠滑环或每圈后解绕。

### R3 【中】激光光斑可能检不到（IR-cut 滤 405nm / 过曝）

**对策（分三层，按代价从低到高）**：

1. 先用 `tools/check_laser.py` 验证，调 `laser.b_min` / `b_minus_others`
   两个阈值（405nm 在相机里是 **B 通道占优**，和红色靶心的 R 占优方向相反，
   所以阈值调低了也不会跟红靶心混）。
2. 位置门控 + 慢速自适应：光斑在画面里的位置是"刚性固定"的，
   门控之外一律不认；某一帧检不到不影响，用上一帧的位置继续跑。
3. 真检不到时才走**兜底**：按靶纸距离查 `calib.boresight_table`
   （`tools/calib_boresight_table.py` 标定，2~3 个距离点，运行时线性插值）。
   为什么不是直接用一个固定像素点：激光装在镜头下面、两轴有平移，
   光斑像素位置是距离的函数（角度 ≈ 两轴夹角 + 平移/距离），
   单点只在标定距离上准，换距离会偏几十像素。

**额外建议**：装镜头时优先用 **无 IR-cut 的模组** 或可拆 IR-cut 的 M12 镜头座，
405nm 会亮得多。若已有 IR-cut，405nm 仍能被 CMOS 响应（量子效率较低但
激光功率密度极高），通常仍能看到。

**更彻底的做法（推荐，等激光接回 GPIO 之后）**：让激光按帧闪烁，
用"亮/暗两帧相减"找光斑。差分图里静态背景（含红色靶心）全部被减掉，
只剩光斑本身 —— 这是唯一能把"光斑"和"红靶心"从原理上分开的办法，
而且能容忍极弱的激光。需要 `LASER_GPIO_ENABLE 1` + `laser.always_on false`。

### R4 【中】曝光两难：压暗光斑 vs 看清黑框

激光极亮 => 想短曝光压暗它；靶纸黑框要看清 => 想长曝光。

**对策**：

- 激光检测用**颜色优势（B - max(R,G)）**而不是绝对亮度，对曝光不敏感
- 优先保证**黑框可见**（长曝光）；光斑即使过曝，只要 B 通道仍是
  最大通道且位置门控通过，仍能稳定检出
- `camera.exposure` 留了手动档，现场可试 1/500s ~ 1/2000s

### R5 【中】靶面可能超出视场（发挥部分第 1 段：小车在 AB 段离靶最近）

小车在 AB 段离靶最近（50cm），此时 A4（210x297mm）对角半角约 20°。

**对策**：相机选 **水平视场 >= 70°**（越宽越好，但太宽会降低焦距、
使 1 像素对应更大的靶面位移）。建议 70°~90°，分辨率 1280x720。
若用 90° 视场，1280 宽 => fx 约 640，1.58m 处 1px 约 2.5mm，
2cm 容差仍有 8px 余量，够用。

### R6 【低】RCT6 掉线 / 地瓜派掉线

- RCT6 掉线：瞄准不受影响，只是失去拐角增强与画圆相位。
  程序打印告警并退化为 `time` 相位。
- 地瓜派掉线：H723 在 0.5s 内收不到 `AIM` 就进入 `STAB` 模式
  （保持当前绝对方位、关激光），**不会乱转**。
- 地瓜派自身异常退出：`app.py` 保证退出前发 `MODE=IDLE` + 关激光；
  即使不发，H723 的看门狗也会接管。

### R7 【低】光照变化 / 靶纸反光

场地要求"周围无强光干扰"，但仍可能遇到顶灯。

**对策**：黑框检测用自适应阈值（对整体亮度不敏感）；
红圈精修与黑框中心做交叉校验，任一路异常自动回退到另一路。

### R8 【低】俯仰轴行程与靶高

靶高 <=50cm，靶心大概在 20~30cm 高度。相机装车后高度约 10~20cm。

| 车到靶距离 | 需要的俯仰角（假设相机 15cm、靶心 25cm） |
|---|---|
| 0.5m | atan(0.10/0.5) = 11.3° |
| 1.0m | 5.7° |
| 1.58m | 3.6° |

行程需求很小，`control.max_pitch_deg = 60` 有很大余量。
但**上电时的初始俯仰角要大致指向靶的方向**，否则扫描阶段要花时间。

## 三、现场作业顺序（建议打印带走）

```
 1. 装车 -> 接线（相机、激光、两根串口）-> 上电
 2. python tools/calib_intrinsic.py    # 若已标定可跳过
 3. python tools/check_laser.py        # 确认光斑可检，记下 boresight_uv
 4. python tools/view_detect.py        # 对着靶纸看检测是否稳定
 5. python main.py unwind              # 解绕（跑完一轮后必须做）
 6. python main.py run                 # 基本要求(2)/(3)
 7. python main.py run --budget 20 --draw   # 行驶 + 画圆
 8. 现场若抖动 -> 只调 control.kp，一次 0.05
 9. 每跑一轮看 out/*.csv 的误差曲线，确认没有持续偏置（有偏置=没收敛完）
```

## 四、和题目原文的对照速查

| 题目原文 | 对应实现 |
|---|---|
| "靶上光斑直径 <=0.5cm" | 激光笔选型决定（405nm <=10mW，出瞳直径小、发散角小） |
| "靶面与 AB 平行，高度 <=50cm" | 靶面近似正对相机，透视矫正后仍能识别 |
| "1.8cm 宽黑色胶带贴出靶纸外轮廓" | `target.py` 主检测目标（黑框四边形） |
| "靶心直径 <=0.1cm" | 不用它直接检测，见 §2.1 |
| "半径 2/4/6/8/10cm 红色圆" | `target.py` 红圈质心精修 + `trajectory.py` 画圆基准 |
| "光斑痕迹距靶心最大距离 D1 <=2cm" | 视觉闭环稳态误差（估算见上） |
| "光斑痕迹与 r=6cm 红圈最大距离 D2 <=2cm" | 以红圈方程为设定点，误差 = 跟踪误差 |
| "同步误差 < 1/4 圈" | `trajectory.py` 拐角事件 1/4 圈硬重同步 |
