# 循迹控制说明 (STM32F103RCT6 / imucar2)

本工程按 `25-aiming-cart` 的底盘思路重写循迹控制:

```text
LINE -> PRE_TURN -> TURN -> LINE
```

普通直线、转弯和重新抓线都先生成车体 `v(m/s)`、`w(rad/s)`, 再换算左右轮目标速度。
去掉了只左转、四弯计圈和按圈停车等赛道专用逻辑。

---

## 1. 引脚

| 引脚 | 用途 |
| --- | --- |
| PA2 / PA3 | USART2 TX/RX, 8 路灰度模块 |
| PA6 / PA7 | TIM3_CH1/CH2, 左电机 |
| PB0 / PB1 | TIM3_CH3/CH4, 右电机 |
| PB6 / PB7 | TIM4 编码器, 左轮 |
| PC6 / PC7 | TIM8 编码器, 右轮 |
| PB14 / PB15 | 软件 I2C, MPU6050 SCL/SDA |
| PC13 | 电机使能开关 SW4 |
| PA9 / PA10 | USART1, 115200 8N1, 向 H723 发送底盘遥测 |
| PA13 / PA14 | SWD 调试口 |

8 路灰度通过 USART2 + DMA 接收, `M=1` 表示压黑线, `M` 从左到右对应 x1~x8。

---

## 2. 车体参数

| 参数 | 数值 |
| --- | ---: |
| 轮距 `wheel_base` | 0.115 m |
| 轮子直径 / 半径 | 6.7 cm / 3.35 cm |
| 编码器一圈 | 13线 × 30减速比 × 4倍频 = 1560 counts |
| 灰度探头间距 | 11.14 mm |
| 灰度排到轮轴距离 | 0.185 m |
| 转弯半径 | 0.062 m |
| 100% PWM 对应轮速 | 342 rpm |

`0.062 m` 大于轮距一半 `0.0575 m`, 因此内轮可以保持正向转动。

底盘里程使用编码器累计计数直接换算为米：

```text
wheel_delta_m =
    Motor_GetDistanceMeters(本次)
    - Motor_GetDistanceMeters(上次)
```

不再使用 `Motor_GetDistanceCm()` 的厘米整数差分，消除每5 ms控制周期
最多约1 cm的里程量化。

## 4. 状态机

遥测 `ST`:

| ST | 状态 | 动作 |
| ---: | --- | --- |
| 0 | `TRACK_LINE` | 直线和普通弯道循迹 |
| 1 | `TRACK_PRE_TURN` | 保持前进, `w=0`, 减速并走到起弧点 |
| 2 | `TRACK_TURN` | IMU积分角度, 差速转向 |
| 3 | `TRACK_REACQUIRE` | 80°后继续转弯并抓取新直边 |
| 4 | `TRACK_LOST` | 丢线后低速找线 |
| 5 | `TRACK_STOP` | 找线超时、传感器掉线或使能关闭 |

## 5. 直线循迹

### 5.1 灰度误差

8个探头位置:

```text
(i - 3.5) × 11.14 mm
```

只有压线1~3路且通道连续时才认为有效:

```text
error_mm = Σ压线位置 / 压线数量
```

位置误差使用35ms低通:

```text
line_error += dt/(0.035+dt) × (error_mm-line_error)
```

误差变化率使用30ms低通。直线误差积分限幅为`±40 mm·s`。

### 5.2 直线角速度

```c
target_w = clamp(
    -0.018 * line_error_mm
    -0.004 * line_derivative
    -0.010 * line_integral
    -0.40  * heading_error,
    -1.5,
     1.5
);
```

其中:

```text
heading_error = IMU航向 - 当前直边方向 - heading_trim
```

黑线居中时缓慢修正 `heading_trim`, 吸收陀螺漂移。

### 5.3 直线角速度反馈

直线和预转弯阶段, 最终送入差速换算的角速度还会叠加:

```c
correction = clamp(
    0.80 * (target_w - gyro_z),
    -1.0,
     1.0
);

wheel_w = target_w + correction;
```

正式 `TURN` 不使用这个额外修正。

### 5.4 直线前向速度

基础速度:

```text
straight = 0.29 m/s
```

上电并使能后第一次获得有效黑线时，目标速度用 `1.20 s` smoothstep 从 0
缓慢升到 `0.29 m/s`：

```text
x = min(t / 1.20, 1.0)
smooth = x² × (3 - 2x)
v_target = 0.29 × smooth
```

该斜坡只在首次起步时使用；进入直角、丢线停车或后续普通直线巡线时不会再次
触发。斜坡完成后，检测到直角并连续确认，PRE_TURN 目标降到 `0.14 m/s`，
再用 `0.60 m/s²` 的减速度平滑过渡。

IMU 实际积分达到90°后立即回到直线。出弯后的 `0.80 s` 内只恢复目标速度
斜坡：

```text
v_target =
    0.14 + (0.29 - 0.14) × min(t / 0.80, 1.0)
```

斜坡期间遥测 `phase=3`，H723 可据此识别出弯恢复阶段。该阶段同时使用
`ff71418` 的低速阻尼缩放：

```text
Kp × 0.60
Kd × 1.25
Ki × 0.25
Kh × 0.50
角速度限幅 = 0.80 rad/s
```

斜坡结束后恢复常规 `Kp/Kd/Ki/Kh`。起步和出弯斜坡不改变直角检测或转弯
半径。

### 5.5 丢线

如果没有有效线:

- 速度降到 `0.08 m/s`
- 保持或根据最后误差方向给出搜索角速度
- 200ms内仍是无效线, 进入 `TRACK_LOST`
- `TRACK_LOST` 继续低速找线700ms
- 超时进入 `TRACK_STOP`

## 6. 直角检测

当前支持左、右直角:

- 一侧至少3路压线
- 另一侧最多2路压线
- 8路全黑不判直角
- 连续3个新的灰度帧确认

检测到后记录本次边距, 进入 `PRE_TURN`。

## 7. 预转弯

预转弯目标:

```text
v = 0.14 m/s
w = 0
```

需要继续直行的距离:

```text
remaining =
    sensor_ahead
    - radius
    - turn_lead_extra
    - turn_lead
    - state_distance
```

其中:

```c
turn_lead = measured_v * (
    turn_lag
    + (turn_v/radius) / (2*angular_accel)
);
```

参数:

```text
turn_lag = 0.20s
angular_accel = 8 rad/s²
turn_lead_extra = 0.020 m
```

进入正式转弯需同时满足:

```text
remaining <= 0
state_time >= 0.06s
|w| < 0.05 rad/s
```

预转弯最长2秒。

---

## 8. 正式转弯

正式转弯时:

```text
v = 0.14 m/s
```

IMU积分本弯角度:

```text
turn_angle += gyro_z * dt
```

剩余角度:

```text
remaining = π/2 - turn_angle - gyro_z*0.20
```

目标角速度:

```c
target_w = min(
    max(body_v, 0.14) / 0.062,
    sqrt(2 * 8.0 * remaining)
);
```

目标车体角速度按 `8 rad/s²` 斜坡逼近该值，接近90°时第二项继续负责
角速度减速。入弯点仍使用上面的 `turn_lead` 公式；该公式本来就包含
`w_turn/(2*8)` 的斜坡时间，因此本次只恢复角速度斜坡，不修改
`sensor_ahead=0.185 m`、`radius=0.062 m` 或预转弯距离，避免额外提前
入弯和扩大实际转弯半径。

当前参数下：

```text
w_turn = 0.14 / 0.062 = 2.258 rad/s
ramp_time = w_turn / 8 = 0.282 s
turn_lead = 0.14 × (0.20 + 2.258/(2×8)) = 0.0478 m
```

其中 `turn_lead` 仍按现有底盘结构和 `sensor_ahead=0.185 m` 参与预转弯
距离计算。

实车左右转弯完成后，车体中轴线均外扩约 `2 cm`。因此增加
`turn_lead_extra=0.020 m`，让两侧转弯都提前约 `2 cm` 起弯，补偿实际
轮速环和车身响应滞后。该项只移动起弯位置，不修改 `radius=0.062 m`、
`turn_v=0.14 m/s` 或左右轮差速。

保护条件:

```text
超过130°       -> 停车
反方向超过15°  -> 停车
超过5秒         -> 停车
```

转弯优先使用MPU6050真实角速度积分。只有IMU短时失效不超过50 ms时，
才临时使用左右轮差速反推角速度；超过50 ms直接判故障。

累计转角达到80°后进入 `TRACK_REACQUIRE`，继续以 `0.14 m/s` 前进和
转弯，同时开始读取新直边：

```text
next_edge_error =
    当前IMU航向 - 新直边目标方向 - heading_trim

target_w = clamp(
    -0.020 × line_error_mm
    -1.50 × next_edge_error,
    -1.50,
     1.50
)
```

只有连续3个新灰度帧同时满足以下条件才回 `LINE`：

```text
|横线误差| <= 1.5 × 11.14 mm
|新直边航向误差| <= 15°
|gyro_z| < 0.35 rad/s
```

该阶段仍使用8 rad/s²的角速度斜坡和转弯内轮最小速度，转弯半径与左右轮
差速保持原有标定。只有抓线完成后才进入0.8秒速度恢复。

## 9. v/w 到左右轮

```c
left_mps  = v - 0.5 * wheel_base * w;
right_mps = v + 0.5 * wheel_base * w;
```

峰值超过电机最大轮速时按比例缩小, 保持曲率。

目标轮速再换算成百分比:

```text
percent = wheel_mps / mps_per_percent
```

左右轮目标交给电机编码器速度环。

## 10. 电机速度环

两个轮子共用一套“前馈+PID”, 与参考底盘结构一致:

```text
Kp = 6.00
Ki = 1.60
Kd = 0.06
积分限幅 = 100%
测速滤波 = 0.45
微分滤波 = 0.15
```

```text
PWM = Kp*误差 + Ki*∫误差 - Kd*实测速度变化率
    + FF
```

前馈使用本车死区附近的基准:

```text
FF = 55% + 0.45 × 目标轮速百分比
```

目标低于5%时, 55%基准按比例淡出, 避免内轮获得过大基准占空比。

目标突然进入低于5%的区域时清除一次旧积分, 防止内轮转弯开始后仍被直线段的大占空比托着。

目标为正时不输出反向驱动。如果实际轮速仍高于目标, 控制器使用两个半桥同时导通的
短接制动, 制动强度上限100%; 制动通道使用普通PID负输出的2倍增益, 实际速度降到
目标附近后立即恢复正向PID输出。

## 11. H723 二进制状态遥测

USART1 PA9/PA10 使用 `115200 8N1`。启动阶段保留少量文本诊断，随后每20ms发送
一帧固定22字节二进制数据，即50Hz。

| 偏移 | 长度 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0 | 1 | `0xAA` | 帧头1 |
| 1 | 1 | `0x55` | 帧头2 |
| 2 | 1 | `version` | 协议版本，当前为5 |
| 3 | 1 | `type` | 底盘状态帧，固定为`0x31` |
| 4 | 2 | `seq` | 小端`uint16_t`，每帧加一 |
| 6 | 1 | `phase` | 底盘阶段 |
| 7 | 1 | `turn_dir` | `int8_t`：+1左转，-1右转，0无方向 |
| 8 | 1 | `flags` | 状态标志 |
| 9 | 1 | `distance_zone` | 0未知、1近边、2远边、3过渡段 |
| 10 | 2 | `speed_mm_s` | 小端`int16_t`，两轮平均实测车体速度 |
| 12 | 2 | `yaw_rate_dps_x10` | 小端`int16_t`，底盘`gyro_z × 10` |
| 14 | 1 | `corner_count` | 已完成的90°直角弯绝对计数 |
| 15 | 1 | `reserved` | 保留，固定为0 |
| 16 | 4 | `sample_ms` | F103 `HAL_GetTick()`采样时刻，小端`uint32_t` |
| 20 | 2 | `crc16` | 小端，覆盖偏移0~19 |

`phase`定义：

| 值 | 含义 |
| --- | --- |
| 0 | `STRAIGHT`，直道正常循迹 |
| 1 | `PRE_TURN`，已确认转弯并准备入弯 |
| 2 | `TURNING`，正在转弯 |
| 3 | `TURN_EXIT`，80°后的新直边抓取及抓稳后的柔和恢复阶段 |
| 4 | `FAULT`，丢线、停车或底盘故障 |

`flags`定义：

| 位 | 含义 |
| --- | --- |
| bit0 | 底盘控制有效：电机使能且当前无故障 |
| bit1 | 转弯方向有效 |
| bit2 | 正在自动循迹 |
| bit3 | 底盘故障：丢线/停车、电机卡滞、IMU离线或转弯方向无效 |
| bit4~7 | 保留，置0 |

`distance_zone`按真实路线转角计数生成：

```text
corner_count % 4 = 0 -> 近边
corner_count % 4 = 2 -> 远边
corner_count % 4 = 1/3 -> 过渡段
```

转角在 `TRACK_REACQUIRE` 连续3帧确认新直边后加一。H723使用该值选择路线几何
前馈比例和视觉距离失效时的距离兜底，不再根据`PIVOT -> EXIT/TRACK`
转换自行猜测。

校验使用 `CRC16-CCITT-FALSE`：初值`0xFFFF`，多项式`0x1021`，不反射，
结果异或值`0x0000`。标准测试向量`"123456789"`的结果为`0x29B1`。

发送周期为 `20 ms`，即 `50 Hz`。TIM2 中断中以 `5 ms` 周期更新状态、
IMU 和轮速；主循环发送遥测前用一次短临界区抓取同一控制时刻的 snapshot，
保证 phase、方向、距离区间、速度、角速度、转角和采样时间戳来自同一个
控制周期。时间戳在临界区内取得，因此 H723 可以判断数据帧在到达前已经
经历了多长时间；H723 同时记录本板接收时刻和两板时钟最小偏移估计。

停车、传感器离线或电机未使能时会清除实测速度，避免把停车前的旧速度继续
发送给 H723。
