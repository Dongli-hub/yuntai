# 循迹控制说明 (STM32F103RCT6 / imucar2)

本工程按 `25-aiming-cart` 的底盘思路重写循迹控制:

```text
LINE -> PRE_TURN -> TURN -> LINE
```

普通直线、转弯和重新抓线都先生成车体 `v(m/s)`、`w(rad/s)`, 再换算左右轮目标速度。
去掉了只左转、四弯计圈和按圈停车等赛道专用逻辑。

---

## 1. 引脚

| 引脚 | 用途 |
| --- | --- |
| PA2 / PA3 | USART2 TX/RX, 8 路灰度模块 |
| PA6 / PA7 | TIM3_CH1/CH2, 左电机 |
| PB0 / PB1 | TIM3_CH3/CH4, 右电机 |
| PB6 / PB7 | TIM4 编码器, 左轮 |
| PC6 / PC7 | TIM8 编码器, 右轮 |
| PB14 / PB15 | 软件 I2C, MPU6050 SCL/SDA |
| PC13 | 电机使能开关 SW4 |
| PA9 / PA10 | USART1, 当前调试口, 以后接 H723 |
| PA13 / PA14 | SWD 调试口 |

8 路灰度通过 USART2 + DMA 接收, `M=1` 表示压黑线, `M` 从左到右对应 x1~x8。

---

## 2. 车体参数

| 参数 | 数值 |
| --- | ---: |
| 轮距 `wheel_base` | 0.115 m |
| 轮子直径 / 半径 | 6.7 cm / 3.35 cm |
| 编码器一圈 | 13线 × 30减速比 × 4倍频 = 1560 counts |
| 灰度探头间距 | 11.14 mm |
| 灰度排到轮轴距离 | 0.185 m |
| 转弯半径 | 0.062 m |
| 100% PWM 对应轮速 | 342 rpm |

`0.062 m` 大于轮距一半 `0.0575 m`, 因此内轮可以保持正向转动。

## 4. 状态机

遥测 `ST`:

| ST | 状态 | 动作 |
| ---: | --- | --- |
| 0 | `TRACK_LINE` | 直线和普通弯道循迹 |
| 1 | `TRACK_PRE_TURN` | 保持前进, `w=0`, 减速并走到起弧点 |
| 2 | `TRACK_TURN` | IMU积分角度, 差速转过90° |
| 3 | `TRACK_LOST` | 丢线后低速找线 |
| 4 | `TRACK_STOP` | 找线超时、传感器掉线或使能关闭 |

## 5. 直线循迹

### 5.1 灰度误差

8个探头位置:

```text
(i - 3.5) × 11.14 mm
```

只有压线1~3路且通道连续时才认为有效:

```text
error_mm = Σ压线位置 / 压线数量
```

位置误差使用20ms低通:

```text
line_error += dt/(0.02+dt) × (error_mm-line_error)
```

误差变化率使用30ms低通。

### 5.2 直线角速度

```c
target_w = clamp(
    -0.020 * line_error_mm
    -0.002 * line_derivative
    -1.5   * heading_error,
    -1.5,
     1.5
);
```

其中:

```text
heading_error = IMU航向 - 当前直边方向 - heading_trim
```

黑线居中时缓慢修正 `heading_trim`, 吸收陀螺漂移。

### 5.3 直线角速度反馈

直线和预转弯阶段, 最终送入差速换算的角速度还会叠加:

```c
correction = clamp(
    2.0 * (target_w - gyro_z),
    -1.0,
     1.0
);

wheel_w = target_w + correction;
```

正式 `TURN` 不使用这个额外修正。

### 5.4 直线前向速度

基础速度:

```text
straight = 0.29 m/s
```

误差越大速度越低:

```text
target_v *= 1 - 0.3 × min(|line_error|/40, 1)
```

约等于转弯前会用边长预测提前减速:

```text
room = expected_edge - distance_since_corner - hold
target_v = min(target_v, sqrt(turn_v² + 2*decel*room))
```

没有已知边长时使用参考默认值 `1.0 m`。

### 5.5 丢线

如果没有有效线:

- 速度降到 `0.08 m/s`
- 保持或根据最后误差方向给出搜索角速度
- 200ms内仍是无效线, 进入 `TRACK_LOST`
- `TRACK_LOST` 继续低速找线700ms
- 超时进入 `TRACK_STOP`

## 6. 直角检测

当前支持左、右直角:

- 一侧至少3路压线
- 另一侧最多2路压线
- 8路全黑不判直角
- 连续3个新的灰度帧确认

检测到后记录本次边距, 进入 `PRE_TURN`。

---

## 7. 预转弯

预转弯目标:

```text
v = 0.14 m/s
w = 0
```

需要继续直行的距离:

```text
remaining =
    sensor_ahead
    - radius
    - turn_lead
    - state_distance
```

其中:

```c
turn_lead = measured_v * (
    turn_lag
    + (turn_v/radius) / (2*angular_accel)
);
```

参数:

```text
turn_lag = 0.20s
angular_accel = 8 rad/s²
```

进入正式转弯需同时满足:

```text
remaining <= 0
state_time >= 0.06s
|w| < 0.05 rad/s
```

预转弯最长2秒。

---

## 8. 正式转弯

正式转弯时:

```text
v = 0.14 m/s
```

IMU积分本弯角度:

```text
turn_angle += gyro_z * dt
```

剩余角度:

```text
remaining = π/2 - turn_angle - gyro_z*0.20
```

目标角速度:

```c
target_w = min(
    max(body_v, 0.14) / 0.062,
    sqrt(2 * 8.0 * remaining)
);
```

第一项立即保持目标曲率, 不再等待低角加速度斜坡; 第二项保证接近90°时
按角加速度减速。轮速变化由电机前馈+PID和D项平滑。

保护条件:

```text
超过130°       -> 停车
反方向超过15°  -> 停车
超过5秒         -> 停车
```

IMU积分到真实90°时立即切回 `LINE`, 不再进入额外的抓线状态。

## 9. v/w 到左右轮

```c
left_mps  = v - 0.5 * wheel_base * w;
right_mps = v + 0.5 * wheel_base * w;
```

峰值超过电机最大轮速时按比例缩小, 保持曲率。

目标轮速再换算成百分比:

```text
percent = wheel_mps / mps_per_percent
```

左右轮目标交给电机编码器速度环。

---

## 10. 电机速度环

两个轮子共用一套“前馈+PID”, 与参考底盘结构一致:

```text
Kp = 6.00
Ki = 1.60
Kd = 0.06
积分限幅 = 100%
测速滤波 = 0.45
微分滤波 = 0.15
```

```text
PWM = Kp*误差 + Ki*∫误差 - Kd*实测速度变化率
    + FF
```

前馈使用本车死区附近的基准:

```text
FF = 55% + 0.45 × 目标轮速百分比
```

目标低于5%时, 55%基准按比例淡出, 避免内轮获得过大基准占空比。

目标突然进入低于5%的区域时清除一次旧积分, 防止内轮转弯开始后仍被直线段的大占空比托着。

目标为正时不输出反向驱动。如果实际轮速仍高于目标, 控制器使用两个半桥同时导通的
短接制动, 制动强度上限100%; 制动通道使用普通PID负输出的2倍增益, 实际速度降到
目标附近后立即恢复正向PID输出。

## 11. 蓝牙调试遥测

USART1 PA9/PA10 使用 `115200 8N1`。上电后先输出一行表头, 之后每50ms输出一行CSV:

```text
D,ms,st,mask,err_x10,turn_x10,yaw_x10,gz_x10,
vt_mm_s,vm_mm_s,wt_mrad_s,lt_mm_s,rt_mm_s,
lr_mm_s,rr_mm_s,lm_mm_s,rm_mm_s,
lp_x10,rp_x10,li_x10,ri_x10,lb_x10,rb_x10,dlcnt,drcnt,imu,en,flt
```

字段说明:

| 字段 | 含义 |
| --- | --- |
| `st` | 0=LINE, 1=PRE_TURN, 2=TURN, 3=LOST, 4=STOP |
| `mask` | 8路灰度状态, bit=1压黑线 |
| `err_x10` | 横向误差, 0.1mm |
| `turn_x10` | IMU本弯累计角, 0.1° |
| `yaw_x10` | 全局航向, 0.1° |
| `gz_x10` | 陀螺Z轴角速度, 0.1°/s |
| `vt_mm_s` | 车体目标前进速度, mm/s |
| `vm_mm_s` | 编码器测得车体速度, mm/s |
| `wt_mrad_s` | 车体目标角速度, mrad/s |
| `lt/rt_mm_s` | 位置层给出的左右轮目标速度, mm/s |
| `lr/rr_mm_s` | 电机目标斜坡后的左右轮目标速度, mm/s |
| `lm/rm_mm_s` | 左右轮编码器实际速度, mm/s |
| `lp/rp_x10` | 左右轮实际PWM, 0.1% |
| `li/ri_x10` | 左右轮速度PID积分项, 0.1% |
| `lb/rb_x10` | 左右轮方向保持短接制动强度, 0.1% |
| `dlcnt/drcnt` | 最近5ms左右编码器脉冲增量 |
| `imu/en/flt` | IMU在线、使能、卡住故障 |
