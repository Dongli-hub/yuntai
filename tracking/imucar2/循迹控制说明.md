# 循迹控制说明 (STM32F103RCT6 / imucar2)

本工程按 `25-aiming-cart` 的底盘思路重写循迹控制:

```text
LINE -> PRE_TURN -> TURN -> LINE
```

普通直线、转弯和重新抓线都先生成车体 `v(m/s)`、`w(rad/s)`, 再换算左右轮目标速度。
去掉了只左转、四弯计圈和按圈停车等赛道专用逻辑。

---

## 1. 引脚

| 引脚 | 用途 |
| --- | --- |
| PA2 / PA3 | USART2 TX/RX, 8 路灰度模块 |
| PA6 / PA7 | TIM3_CH1/CH2, 左电机 |
| PB0 / PB1 | TIM3_CH3/CH4, 右电机 |
| PB6 / PB7 | TIM4 编码器, 左轮 |
| PC6 / PC7 | TIM8 编码器, 右轮 |
| PB14 / PB15 | 软件 I2C, MPU6050 SCL/SDA |
| PC13 | 电机使能开关 SW4 |
| PA9 / PA10 | USART1, 当前调试口, 以后接 H723 |
| PA13 / PA14 | SWD 调试口 |

8 路灰度通过 USART2 + DMA 接收, `M=1` 表示压黑线, `M` 从左到右对应 x1~x8。

## 2. 车体参数

| 参数 | 数值 |
| --- | ---: |
| 轮距 `wheel_base` | 0.115 m |
| 轮子直径 / 半径 | 6.7 cm / 3.35 cm |
| 编码器一圈 | 13线 × 30减速比 × 4倍频 = 1560 counts |
| 灰度探头间距 | 11.14 mm |
| 灰度排到轮轴距离 | 0.185 m |
| 转弯半径 | 0.062 m |
| 100% PWM 对应轮速 | 342 rpm |

`0.062 m` 大于轮距一半 `0.0575 m`, 因此内轮可以保持正向转动。

## 4. 状态机

遥测 `ST`:

| ST | 状态 | 动作 |
| ---: | --- | --- |
| 0 | `TRACK_LINE` | 直线和普通弯道循迹 |
| 1 | `TRACK_PRE_TURN` | 保持前进, `w=0`, 减速并走到起弧点 |
| 2 | `TRACK_TURN` | IMU积分角度, 差速转过90° |
| 3 | `TRACK_LOST` | 丢线后低速找线 |
| 4 | `TRACK_STOP` | 找线超时、传感器掉线或使能关闭 |

## 5. 直线循迹

### 5.1 灰度误差

8个探头位置:

```text
(i - 3.5) × 11.14 mm
```

只有压线1~3路且通道连续时才认为有效:

```text
error_mm = Σ压线位置 / 压线数量
```

位置误差使用35ms低通:

```text
line_error += dt/(0.035+dt) × (error_mm-line_error)
```

误差变化率使用30ms低通。

### 5.2 直线角速度

```c
target_w = clamp(
    -0.018 * line_error_mm
    -0.004 * line_derivative
    -0.010 * line_error_integral
    -0.40  * heading_error,
    -1.5,
     1.5
);
```

其中:

```text
heading_error = IMU航向 - 当前直边方向 - heading_trim
```

黑线误差在约一个探头间距内时修正 `heading_trim`, 吸收陀螺漂移。
横向积分项用于消除一至两个探头间距的静态偏线。

### 5.3 直线角速度反馈

直线和预转弯阶段, 最终送入差速换算的角速度还会叠加:

```c
correction = clamp(
    0.8 * (target_w - gyro_z),
    -1.0,
     1.0
);

wheel_w = target_w + correction;
```

正式 `TURN` 不使用这个额外修正。

### 5.4 直线前向速度

基础速度:

```text
straight = 0.29 m/s
```

所有正常直线段保持相同的 `0.29 m/s`, 不根据灰度误差或边长修改基础速度。
转弯结束后的0.8秒内, 目标速度从 `0.14 m/s` 平滑恢复到 `0.29 m/s`。
同一恢复期内使用更柔和的直线增益和 `0.8 rad/s` 角速度限幅, 减少出弯瞬间
数字灰度跨探头造成的左右振动; 0.8秒后平滑恢复到完整直线控制。

### 5.5 丢线

如果没有有效线:

- 速度降到 `0.08 m/s`
- 保持或根据最后误差方向给出搜索角速度
- 200ms内仍是无效线, 进入 `TRACK_LOST`
- `TRACK_LOST` 继续低速找线700ms
- 超时进入 `TRACK_STOP`

## 6. 直角检测

当前支持左、右直角:

- 一侧至少3路压线
- 另一侧最多2路压线
- 8路全黑不判直角
- 连续3个新的灰度帧确认

检测到后记录本次边距, 进入 `PRE_TURN`。

---

## 7. 预转弯

预转弯目标:

```text
v = 0.14 m/s
w = 0
```

需要继续直行的距离:

```text
remaining =
    sensor_ahead
    - radius
    - turn_lead
    - state_distance
```

其中:

```c
turn_lead = measured_v * (
    turn_lag
    + (turn_v/radius) / (2*angular_accel)
);
```

参数:

```text
turn_lag = 0.20s
angular_accel = 8 rad/s²
```

进入正式转弯需同时满足:

```text
remaining <= 0
state_time >= 0.06s
|w| < 0.05 rad/s
```

预转弯最长2秒。

---

## 8. 正式转弯

正式转弯时:

```text
v = 0.14 m/s
```

IMU积分本弯角度:

```text
turn_angle += gyro_z * dt
```

剩余角度:

```text
remaining = π/2 - turn_angle - gyro_z*0.20
```

目标角速度:

```c
target_w = min(
    max(body_v, 0.14) / 0.062,
    sqrt(2 * 8.0 * remaining)
);
```

第一项立即保持目标曲率, 不再等待低角加速度斜坡; 第二项保证接近90°时
按角加速度减速。轮速变化由电机前馈+PID和D项平滑。

保护条件:

```text
超过130°       -> 停车
反方向超过15°  -> 停车
超过5秒         -> 停车
```

退出时使用 `陀螺角速度 × 0.08s` 预测车体惯性残余角, 达到预测目标后立即切回
`LINE`, 让车体在直线上完成最后几度, 避免每个弯多转约5°并逐弯累积。

---

## 9. v/w 到左右轮

```c
left_mps  = v - 0.5 * wheel_base * w;
right_mps = v + 0.5 * wheel_base * w;
```

峰值超过电机最大轮速时按比例缩小, 保持曲率。

目标轮速再换算成百分比:

```text
percent = wheel_mps / mps_per_percent
```

左右轮目标交给电机编码器速度环。

---

## 10. 电机速度环

两个轮子共用一套“前馈+PID”, 与参考底盘结构一致:

```text
Kp = 6.00
Ki = 1.60
Kd = 0.06
积分限幅 = 100%
测速滤波 = 0.45
微分滤波 = 0.15
```

```text
PWM = Kp*误差 + Ki*∫误差 - Kd*实测速度变化率
    + FF
```

前馈使用本车死区附近的基准:

```text
FF = 55% + 0.45 × 目标轮速百分比
```

目标低于5%时, 55%基准按比例淡出, 避免内轮获得过大基准占空比。

目标突然进入低于5%的区域时清除一次旧积分, 防止内轮转弯开始后仍被直线段的大占空比托着。

目标为正时不输出反向驱动。如果实际轮速仍高于目标, 控制器使用两个半桥同时导通的
短接制动, 制动强度上限100%; 制动通道使用普通PID负输出的2倍增益, 实际速度降到
目标附近后立即恢复正向PID输出。

## 11. H723 二进制状态帧

USART1 PA9/PA10 使用 `115200 8N1`。二进制协议以50Hz发送固定16字节帧:

| 偏移 | 长度 | 字段 | 值 |
| ---: | ---: | --- | --- |
| 0 | 1 | 帧头1 | `0xAA` |
| 1 | 1 | 帧头2 | `0x55` |
| 2 | 1 | version | `1` |
| 3 | 1 | type | `0x31` |
| 4 | 2 | seq | 小端, 每帧加1 |
| 6 | 1 | phase | 底盘阶段 |
| 7 | 1 | turn_dir | `+1`左, `-1`右, `0`直行 |
| 8 | 1 | flags | 状态标志 |
| 9 | 1 | reserved | `0` |
| 10 | 4 | chassis_ms | 小端底盘毫秒时钟 |
| 14 | 2 | crc16 | 对偏移0~13计算, 小端 |

`phase`:

| 值 | 阶段 |
| ---: | --- |
| 0 | `STRAIGHT` 直道正常循迹 |
| 1 | `PRE_TURN` 已确认即将转弯 |
| 2 | `TURNING` 正在转弯 |
| 3 | `TURN_EXIT` 转弯结束后的0.8秒恢复期 |
| 4 | `FAULT` 丢线、传感器掉线、IMU离线或电机故障 |

`flags`:

| 位 | 含义 |
| ---: | --- |
| bit0 | 底盘控制有效 |
| bit1 | 转弯方向有效 |
| bit2 | 正在自动循迹 |
| bit3 | 底盘故障 |

CRC 使用 **CRC-16/CCITT-FALSE**:

```text
poly=0x1021, init=0xFFFF, refin=false, refout=false, xorout=0
```

基准帧 `seq=0, phase=STRAIGHT, turn_dir=0, flags=0x05, chassis_ms=0`:

```text
AA 55 01 31 00 00 00 00 05 00 00 00 00 00 A2 15
```

H723应使用自己的串口接收时间做控制补偿, 不直接使用 `chassis_ms`。

当前为了现场排障默认使用可读CSV遥测。接H723时在 `link.h` 切换:

```c
#define LINK_BINARY_TELEMETRY 1
#define LINK_DEBUG_TELEMETRY  0
```

当前默认值相反:

```c
#define LINK_BINARY_TELEMETRY 0
#define LINK_DEBUG_TELEMETRY  1
```
